# React Bits components

These components come from [React Bits](https://github.com/DavidHDev/react-bits) by David Haz,
used under its MIT + Commons Clause license (see the original repository).

| File | Used for |
|---|---|
| `DecryptedText.jsx` | Screen headings that "decrypt" into place |
| `SpotlightCard.jsx` | The five warning-sign cards |
| `Noise.jsx` | Paper grain over the whole page |
| `Magnet.jsx` | Magnetic main buttons (mouse only; off for touch and reduced motion) |
| `CountUp.jsx` | The final score |
| `ScrollVelocity.jsx` | The "caution tape" of scam phrases on the opening screen |

They are copied unchanged, so they can be updated from the source.
